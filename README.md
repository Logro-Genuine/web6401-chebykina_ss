# Лабораторная работа №2

В данной лабораторной работе, направленной на изучение основ HTML и CSS, было сделано:

- Созданы 5 страниц сайта: главная, страница курса, личный кабинет ученика, результаты обучения и страница урока.
- Добавлены ссылки для перехода между страницами.
- Добавлены обложки курсов и аватары ученика и преподавателя.
- На странице результатов создана таблица с выравниванием текста слева, по центру и справа.
- Оформление вынесено в отдельный файл `style.css`. Использованы селекторы тегов, классов и идентификаторов.
- Для оформления выбраны светлый фон и желтые акценты, связанные с идеей "ученье - свет".

Сайт называется "ЛЮМЕНАР". За основу взята идея платформы с онлайн-курсами наподобие Stepik. В каталоге можно выбрать курс HTML, прочитать его описание и перейти к первому уроку. Остальные два курса пока представлены только карточками.

Сайт написан на HTML и CSS, без JavaScript и библиотек. Данные в личном кабинете и результаты обучения заполнены вручную и не обновляются автоматически.

Все файлы находятся в папке `lab2`. Чтобы посмотреть сайт, нужно открыть `lab2/index.html` в браузере.

# Лабораторная работа №3

Данная лабораторная работа была направлена на изучение основ JavaScript. В её ходе было выполнено следующее:

- Функция `isInteger` использует побитовый оператор `|`. Она возвращает `true` для целых чисел от −2³¹ до 2³¹ − 1 включительно.
- Создана функция, которая возвращает массив четных чисел от 2 до 20.
- Написаны две функции для подсчета суммы чисел от 1 до n: через цикл и через рекурсию.
- Реализованы вычисление факториала, проверка степени двойки и поиск числа Фибоначчи.
- Написана функция, которая сохраняет результат операции между вызовами с помощью замыкания.
- Создан генератор арифметической последовательности с начальным значением и шагом.
- Реализовано рекурсивное сравнение содержимого объектов и массивов.
- Добавлены проверки аргументов для рекурсивной суммы, факториала и числа Фибоначчи.

Все 10 функций находятся в файле `lab3/js-tasks-main/src/core.js`. Для проверки использованы готовые тесты из `core.spec.js`.

# Лабораторная работа №4

За основу взят сайт "ЛЮМЕНАР" из второй лабораторной. Его копия находится в папке `lab4`.

- Главная страница и карточки курсов сверстаны с помощью Flexbox.
- Личный кабинет сверстан с помощью Grid. На узком экране блоки идут в одну колонку.
- Все цвета вынесены в CSS-переменные в `:root`.
- При открытии главной страницы проигрывается анимация: солнце с жёлтым ореолом поднимается из-за горизонта, а фон меняется с голубого через персиковый на светло-жёлтый.
- В личный кабинет добавлена форма заявки: имя (`text`), почта (`email`), выбор курса (`select`) и согласие (`checkbox`).
- После проверки полей создаётся объект класса `CourseApplication`; конструктор сохраняет введённые данные; метод `print()` выводит их в консоль браузера через `console.table` перед отправкой на сервер.
- Форма отправляет JSON на локальный сервер. При успехе появляется подтверждение, а при ошибке данные остаются в форме для повторной отправки.
- Для имен классов использована методология БЭМ, например `profile__about` и `application__status--error`.

Для проверки отправки формы необходимо перейти в личный кабинет, заполнить форму и нажать «Отправить заявку». В консоли браузера во вкладке Network будет видет POST-запрос. Если запрос к `/api/applications` корректный, то будет код ответа 201.

Сервер учебный, то есть проверяет и принимает заявку без сохранения в БД.
