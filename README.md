# Лабораторная работа №2

В данной лабораторной работе, направленной на изучение основ HTML и CSS, было сделано:

- Созданы 5 страниц сайта: главная, страница курса, личный кабинет ученика, результаты обучения и страница урока.
- Добавлены ссылки для перехода между страницами.
- Добавлены обложки курсов и аватары ученика и преподавателя.
- На странице результатов создана таблица с выравниванием текста слева, по центру и справа.
- Оформление вынесено в отдельный файл `style.css`. Использованы селекторы тегов, классов и идентификаторов.
- Для оформления выбраны светлый фон и желтые акценты, связанные с идеей "ученье - свет".

Сайт называется "ЛЮМЕНАР". За основу взята идея платформы с онлайн-курсами наподобие Stepik. В каталоге можно выбрать курс HTML, прочитать его описание и перейти к первому уроку. Остальные два курса пока представлены только карточками.

Сайт написан на HTML и CSS, без JavaScript и библиотек. Данные в личном кабинете и результаты обучения заполнены вручную и не обновляются автоматически.

Все файлы находятся в папке `lab2`. Чтобы посмотреть сайт, нужно открыть `lab2/index.html` в браузере.
