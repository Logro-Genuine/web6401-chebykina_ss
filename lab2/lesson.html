Что такое HTML

HTML - язык разметки, который описывает структуру веб-страницы. С его помощью браузер определяет, где находятся заголовки, абзацы, списки и другие элементы.

Большинство элементов состоит из открывающего тега, содержимого и закрывающего тега. Например, тег p обозначает абзац.

Пример разметки

<h1>Моя первая страница</h1>
<p>Привет! Я изучаю HTML на ЛЮМЕНАР.</p>

В этом примере h1 задаёт главный заголовок, а p - абзац текста.

Атрибуты элементов

Атрибуты задают дополнительные свойства. Например, атрибут href у ссылки указывает адрес перехода.

<a href="index.html">На главную</a>

Практическое задание

  1. Создай файл с расширением .html в текстовом редакторе.
  2. Добавь заголовок со своим именем и абзац о том, что хочешь изучить.
  3. Сохрани файл и открой его в браузере.

Проверь себя: заголовок должен отображаться крупнее текста абзаца.
